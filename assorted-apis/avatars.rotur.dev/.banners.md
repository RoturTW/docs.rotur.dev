# .banners

Get a user's profile banner instead of their profile picture.

### How do I get a banner?

Same as a profile picture, but with `.banners` in front of the username:

* https://avatars.rotur.dev/.banners/mist
* https://avatars.rotur.dev/.banners/MiSt

### About

* Banners are stored at 900x300 and served as JPEG, PNG or GIF depending on what was uploaded
* If the user has no banner, you get a tiny 3x1 transparent image
* Responses are cached (`ETag` and `Cache-Control: max-age=300`)

### Animated banners

Animated GIF banners only play if the user has a **Pro** subscription or higher. For everyone else the first frame is served as a still JPEG. Add `?no_animate=1` to force a still image regardless of tier.

### Query Parameters

| Parameter | Description |
|---|---|
| `radius` | Corner radius in pixels (a `px` suffix is accepted). Example: `?radius=16` |
| `no_animate` | Set to `1` to always get a still image |
