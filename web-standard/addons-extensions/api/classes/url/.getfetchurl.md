# .getFetchUrl()

Returns the address the URL's content is fetched from. [`.getAsyncData()`](.getasyncdata.md) uses it.

For web URLs, the browser looks up the host for the top-level domain and appends the domain, path, and file name. For local URLs, it returns the file path.

| URL | Fetch URL |
| --- | --- |
| `web://bouncy.flf` | `<host for .flf>/bouncy.flf/index.osl` |
| `local://~/Pages/myPage.owf` | `~/Pages/myPage.owf` |
