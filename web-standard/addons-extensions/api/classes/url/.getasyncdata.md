# .getAsyncData()

Fetches the content at the URL without blocking, like [OSL's `.getAsync()`](https://osl.mistium.com/methods/networking/.getasync) but called on a URL instance. It fetches from the address returned by [`.getFetchUrl()`](.getfetchurl.md).

In the Flufi Browser it returns `"Loading"` until the content is available.

## Implementations

{% tab title="Flufi Browser (OSL)" %}
Code in the URL class:

```javascript
switch self.scheme (
  case "rtr"; case "local"
    return getAsync(self.getFetchUrl())
    break
)
```

The `getAsync` function:

```javascript
def getAsync(url) (
  if url.startsWith("origin/") or url.startsWith("~") or url.startsWith("/") (
    local data = open(getPath(url),[4])
    if data[1] != "" (
      return data[1]
    ) else (
      return "Loading"
    )
  )
  if url.startsWith("https://") (
    return url.getAsync()
  )
  return "Loading"
)
```
