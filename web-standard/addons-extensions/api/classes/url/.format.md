# .format()

Returns the URL as a string. For example, this URL:

```json
{
    "scheme": "web",
    "domain_name": "bouncy",
    "domain_top": "flf",
    "domain_sub": "wow",
    "path": "subdir/subdir2",
    "params": {
        "test": "wow",
        "crazy": "noway"
    },
    "file_name": "shocker.txt"
}
```

becomes `web://wow.bouncy.flf/subdir/subdir2/shocker.txt?test=wow&crazy=noway`.

```javascript
local sub = self.domain_sub != null ? self.domain_sub ++ "." ""
local top = self.domain_top != null ? "." ++ self.domain_top ""
local txt = self.scheme ++ "://" ++ sub ++ domain_name ++ top
if self.path != null (
  txt ++= "/" ++ self.path
)
if self.file_name != "index.osl" (
  txt ++= "/" ++ self.file_name
)
return txt
```
