# .getTitle()

Returns the page title. If the page has no title, returns the title from its URL (see [URL `.getTitle()`](../url/.gettitle.md)).

Calling it on the class instead of an instance throws `instance function ran on non-instance`.

## Implementations

{% tabs %}
{% tab title="Flufi Browser (OSL)" %}
```javascript
if self.isInstance.not() (
  throw "instance function ran on non-instance"
)

return self.title ?? self.url.getTitle()
```
