# Events

A browser calls an extension's handlers when these events happen.

| Event | When it fires | Parameters |
| --- | --- | --- |
| [`onload`](onload.md) | The extension first loads | None |
| [`page_load`](page_load.md) | A page loads | The [Page](../api/classes/page/README.md) that loaded |
| [`page_focus`](page_focus.md) | A page is focused | The [Page](../api/classes/page/README.md) that was focused |
