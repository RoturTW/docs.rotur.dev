# Variables

Pages set or read these variables to exchange information with the browser.

| Variable | Direction | Description |
| --- | --- | --- |
| [`tab_info`](tab_info.md) | Set by the page | The tab's title and icon |
| [`page_width` / `page_height`](page_width-height.md) | Set by the page | The size of the frame the page is drawn in |
| [`scroll_x` / `scroll_y`](scroll_x-y.md) | Read by the page | The current scroll position of the frame |
