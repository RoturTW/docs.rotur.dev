# Addons / Extensions

Extensions add behavior to a Rotur web browser. An extension is a definition object with metadata and a set of event handlers, and it can use the browser API, commands, and variables described in this section.

| Page | Contents |
| --- | --- |
| [Basic structure](basic-structure.md) | The fields an extension definition contains |
| [Events](events/README.md) | `onload`, `page_load`, `page_focus` |
| [API](api/README.md) | The `Page` and `URL` classes |
| [Commands](commands/README.md) | `redirect`, `opentab` |
| [Variables](variables/README.md) | `tab_info`, `page_width` / `page_height`, `scroll_x` / `scroll_y` |
