# Functions

RTR's built-in functions, grouped by category. Call them like any other function: `name(arguments)`.

| Category | Functions |
| --- | --- |
| [Math](math.md) | `min`, `max`, `abs`, `round`, `floor`, `ceil`, `sqrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan` |
| [String](string.md) | `join`, `split`, `chr`, `ord`, `length`, `toStr` |
| [Array](array.md) | `length`, `item`, `range` |
| [Object](object.md) | `obj`, `keys`, `values`, `has`, `set`, `del` |
| [Logical](logical.md) | `all`, `any`, `not` |
| [Utility](utility.md) | `log`, `return`, `typeof`, `type`, `toNum`, `input` |

Built-in functions live in the outermost scope. Assigning a variable with the same name, such as `length = 5`, hides the built-in in that scope.
