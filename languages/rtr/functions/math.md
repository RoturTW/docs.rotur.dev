# Math functions

| Function | Returns |
| --- | --- |
| `min(a, b, ...)` | The smallest argument |
| `max(a, b, ...)` | The largest argument |
| `abs(x)` | The absolute value of `x` |
| `round(x)` | `x` rounded to the nearest integer. Halves round up. |
| `floor(x)` | `x` rounded down |
| `ceil(x)` | `x` rounded up |
| `sqrt(x)` | The square root of `x` |
| `sin(x)`, `cos(x)`, `tan(x)` | Sine, cosine, and tangent of `x`, in radians |
| `asin(x)`, `acos(x)`, `atan(x)` | Inverse sine, cosine, and tangent, in radians |

## min

```js
min(5, 3, 8)    /* 3 */
min(-1, -5, 0)  /* -5 */
```

## max

```js
max(5, 3, 8)    /* 8 */
max(-1, -5, 0)  /* 0 */
```

## abs

```js
abs(-5)    /* 5 */
abs(3.14)  /* 3.14 */
```

## round

```js
round(3.7)   /* 4 */
round(3.2)   /* 3 */
round(-3.7)  /* -4 */
```

## floor

```js
floor(3.7)   /* 3 */
floor(3.2)   /* 3 */
floor(-3.7)  /* -4 */
```

## ceil

```js
ceil(3.7)   /* 4 */
ceil(3.2)   /* 4 */
ceil(-3.7)  /* -3 */
```

## sqrt

```js
sqrt(16)  /* 4 */
sqrt(2)   /* 1.4142135623730951 */
```

## Trigonometry

```js
sin(0)  /* 0 */
cos(0)  /* 1 */
```
