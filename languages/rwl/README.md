# RWL

RWL (Rotur Web Language) describes the layout and content of Rotur websites. You write a tree of elements, such as text, frames, and sections, and set their appearance with attributes. For custom drawing and logic, an RWL page can include a script, usually written in [RTR](../rtr/README.md).

The reference parser is in the [RoturTW/.rwl](https://github.com/RoturTW/.rwl) repository.
