# .banners

Get a user's profile banner.

> **Base URL:** `https://avatars.rotur.dev`
>
> **Auth:** None.

## GET `/.banners/:username`

Returns the user's banner. Also accepts `HEAD`. Also available at `/v2/avatars/:username/banner`.

**Auth:** None.

It works like a profile picture, with `.banners` in front of the username:

* https://avatars.rotur.dev/.banners/mist
* https://avatars.rotur.dev/.banners/MiSt

You can pass a 36-character user ID instead of a username, and a `.gif` suffix is accepted and ignored.

Banners are stored at 900×300 and served as JPEG, PNG or GIF, matching what was uploaded. If the user has no banner, you get a 3×1 transparent image. Responses carry `Cache-Control: public, max-age=300, must-revalidate`, and an `ETag` when the user has a banner.

Animated GIF banners only play for users with a Plus subscription or higher. For everyone else, the first frame is served as a still JPEG.

### Parameters

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | string | Yes | A username or 36-character user ID |
| `radius` | query | integer | No | Corner radius in pixels. A `px` suffix is accepted. Example: `?radius=16` |
| `no_animate` | query | string | No | `1` always returns a still image |

### Example

```http
GET /.banners/mist?radius=16
```

**Response `200`:** the image bytes.

### Errors

| Status | When |
| --- | --- |
| `400` | A 36-character ID was given and no user has it (`User not found`) |
