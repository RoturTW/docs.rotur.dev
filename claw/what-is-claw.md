# What is claw

Claw is a simple, rotur-based social media platform without an algorithm. Just a single feed. It's an easy way for you to add social functionality to your rotur client operating systems.

Everything runs over plain HTTP requests to `https://api.rotur.dev`, so you can build a Claw client in anything that can make a web request. See [Api Endpoints](api-endpoints/README.md) for the full reference.
